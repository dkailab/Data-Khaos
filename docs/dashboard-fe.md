四、图表渲染引擎要求

要求项	说明
渲染引擎	ECharts 5.4+，所有图表类型基于ECharts实现
动态渲染	数据变更时图表平滑过渡动画
响应式	窗口缩放时图表自动适配容器尺寸（ResizeObserver监听）
空状态	无数据时显示友好的空状态占位图

错误状态	数据异常时显示错误提示及重试按钮

六、响应式与性能要求
6.1 性能指标
指标	要求
首屏加载时间	≤ 2秒
拖拽响应延迟	≤ 16ms（60fps）
图表渲染时间	≤ 500ms（1000条数据以内）
大数据渲染	支持10000条数据的渲染（虚拟滚动或数据采样）
内存占用	单个分析板 ≤ 200MB
组件数量	单分析板支持 ≥ 50个组件
6.2 性能优化策略
策略	实现方式
懒加载	非当前Tab的分析板延迟加载
虚拟滚动	大量组件时采用虚拟滚动渲染
数据缓存	查询结果缓存，相同配置不重复请求
防抖/节流	拖拽/缩放操作使用throttle，查询输入使用debounce
图表销毁	组件不可见时销毁ECharts实例释放内存
Web Worker	大数据量计算移至Worker线程
