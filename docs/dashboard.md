三、展示层详细功能设计
3.1 资产池与数据源选择区
3.1.1 数据源类型
已建立的数据集（基于数据表、视图或自定义SQL）

业务线标准指标维度组

3.1.2 资产池展示
以卡片或列表形式展示可用数据资产

支持搜索、筛选（按业务线/类型）和分类

3.1.3 字段列表与类型识别
选中数据源后，自动展示字段列表

自动划分字段类型：

维度（Dimension）：文本型、日期型字段

指标（Measure）：数值型字段

支持字段的显示名称别名设置

3.1.4 拖拽交互
支持将维度/指标从资产池拖拽至分析板的图表配置区

支持拖拽排序（维度优先级、指标顺序）

3.2 分析板（画布）工作区
3.2.1 仪表板结构
一个仪表板可包含多个分析板（类似多标签页）

分析板之间数据隔离，但可复用同一数据集

3.2.2 分析板管理
操作	说明
新增分析板	在当前仪表板中创建新的分析板
重命名	修改分析板名称
复制	复制当前分析板及其所有配置
删除	删除当前分析板
排序	拖拽调整分析板Tab顺序
3.2.3 画布布局
自由布局模式，支持拖拽调整组件位置

支持组件拖拽缩放大小

支持网格对齐（辅助排版）

提供多尺寸画布预设（如 1920×1080、iPad、手机等）

3.2.4 组件容器（分析板内）
每个分析板可包含多个图表组件，每个组件独立配置：

数据绑定（选数据集 + 拖拽维度/指标）

图表类型选择

过滤器配置

样式配置

3.3 可视化图表组件库
3.3.1 图表类型清单
类别	图表类型	用途说明
表格类	表格	明细数据或简单汇总展示
表格类	透视表	多维度交叉分析
对比类	柱状图	类别间数值对比
对比类	条形图	横向类别对比（适合类别名较长）
趋势类	折线图	数据随时间变化趋势
趋势类	面积图	累积趋势展示
占比类	饼图	部分占整体的比例构成
占比类	环形图	饼图的变体，视觉更简洁
分布类	散点图	两个变量间的关系分布
分布类	气泡图	三维数据展示（X/Y/大小）
监控类	仪表盘	单个关键KPI实时监控
地理类	地图（中国/世界）	数据在地理区域上的分布
流程类	漏斗图	各环节转化与流失分析
综合类	雷达图	多维度综合评估
树结构	矩形树图	层级数据的占比展示
3.3.2 图表配置项
数据配置：维度（分组）、指标（数值）、颜色映射、工具提示

样式配置：标题、图例位置、颜色主题、坐标轴标签格式

数值格式：单位（万/亿/无）、小数位数、百分比/千分位

3.4 查询与结果交互区
3.4.1 查询执行
每个分析板或组件可独立执行查询

点击「查询」按钮后，系统根据当前拖拽的维度、指标和过滤器生成查询语句

支持实时预览（配置变更时自动刷新，可配置开关）

3.4.2 图表类型切换
查询结果渲染后，用户可通过图表类型切换器一键切换图表

示例：从「表格」切换到「饼图」→「折线图」，数据源不变，展示形式变化

3.4.3 图表交互
交互能力	说明
图表明细查看	点击图表数据点，弹出详细数据
联动分析	点击图表中的维度值（如"北京"），联动刷新同分析板内其他图表
钻取分析	支持下钻（如从"年"下钻到"月"到"日"）和上卷
数据排序	支持按指标升序/降序排列
数据筛选（图表内）	在图例中点击筛选显示/隐藏特定系列
3.4.4 数据计算能力
汇总方式：求和、平均值、计数、去重计数、最大值、最小值

快速计算：同比、环比、占比、累计值、移动平均

自定义计算字段：支持在数据集层面添加计算字段（如 利润 = 销售额 - 成本）

3.4.5 样式快速配置
图表标题（文本、字号、位置）

颜色主题（预设多套配色方案）

图例位置（上/下/左/右/隐藏）

数值格式（单位、小数位、百分比样式）

3.5 仪表板管理与发布
3.5.1 仪表板管理
功能	说明
创建仪表板	新建一个空的仪表板容器
目录管理	按文件夹/项目分组管理仪表板
另存为	基于当前仪表板复制创建新版本
导出/导入	导出JSON配置，支持跨环境导入
模板市场	将常用仪表板保存为模板，快速复用
3.5.2 保存与发布
草稿状态：编辑中的配置自动保存为草稿，不影响线上版本

发布操作：点击「发布」将当前草稿固化为正式版本

版本管理：支持查看发布历史，并可回滚至任一历史版本

3.5.3 分享与协作
分享方式	说明
链接分享	生成访问链接，支持设置有效期
密码保护	为分享链接设置访问密码
内嵌集成	通过iframe嵌入到其他业务系统
权限管理	设置查看权限（仅本人/指定用户/全部用户）
定时推送	配置定时任务，通过邮件/企微/钉钉推送仪表板截图或链接
